# 🚗 Lotus Car Dealership Website

A modern, responsive **car dealership website** built using **HTML, CSS, and JavaScript**, designed to showcase luxury, sports, and mid-range vehicles with an elegant UI and interactive features.

---

## 📌 Project Overview

This project simulates a premium car dealership platform named **Lotus Cars**, where users can:

- Browse different categories of cars  
- View detailed specifications of each model  
- Explore pricing, features, and performance stats  
- Book a test drive through an interactive form  

The design focuses on a **luxury aesthetic**, smooth transitions, and a **user-friendly interface**.

## ✨ Features

### 🏠 Homepage (indimp.html)
- Hero section with branding and tagline  
- Navigation bar with smooth scrolling  
- Car categories:
  - Sport  
  - Luxury  
  - Mid-Range  
- Interactive tabs to switch between categories  
- Car cards with image, name, and price  
- About/Features section  
- Footer with contact details  

---

### 🚘 Car Detail Page (carimp.html)
- Dynamic car data loaded using **JavaScript objects**
- Displays:
  - Car name, category, and tagline  
  - Price and performance stats  
  - Engine & dimension specifications  
  - Feature highlights  
- URL-based routing:

carimp.html?car=lotus-vortex-rs

- Fully dynamic content injection (no backend required)

---

### 📊 Performance Stats Section
- Horsepower  
- Torque  
- Acceleration (0–100 km/h)  
- Top speed  

---

### 🧾 Booking System (Modal Form)
- “Book Test Drive” button opens modal  
- Input fields:
- Name  
- Email  
- Phone  
- Preferred date  
- Basic validation (e.g., phone number length)  
- Success message after submission
